Features

🎭

Real-Time Face Swap

Swap faces in real-time using your webcam with AI-powered technology.

👄

Mouth Mask

Retain your original mouth for accurate movement using the mouth mask feature.

👥

Multi-Face Mapping

Use different faces on multiple subjects simultaneously in any scene.

🎬

Video Processing

Process videos with face replacement powered by ONNX inference.

📷

Live Camera

Works with any camera feed for live streaming and video calls.

⚡

GPU Accelerated

Supports NVIDIA CUDA, AMD DirectML, and Apple CoreML for maximum performance.

Quick Start — 3 Steps

1

Select a Face

Choose the source face image you want to use for swapping.

2

Choose Camera

Select which camera or video input to use for the live feed.

3

Press Live!

Click the live button and watch the real-time face swap in action.

System Requirements

  • Python 3.10 or 3.11
  • pip package manager
  • git
  • ffmpeg
  • NVIDIA GPU (CUDA) or AMD GPU (DirectML) or Apple Silicon (CoreML)
  • Visual Studio 2022 Runtimes (Windows)
